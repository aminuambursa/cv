California Housing Price Prediction · Machine Learning

  • Showed with bootstrap tests that the model rankings were significant (p < 0.001).

Neural Network Regression (MLP)

  • Selected the architecture by random search over 30 configurations (4 hidden layers, dropout 0.2, early stopping).
  • Regularisation cut the train–test RMSE gap from ≈$21.0k to ≈$2.0k, giving the best generalisation of the four models.

Amazon Digital Music Review Sentiment · NLP and Network Analysis

  • Classified sentiment on 123,994 reviews using TF-IDF, VADER, LDA topics and product co-review network features.

Object Detection with YOLOv8 · Computer Vision
